# ADR-0002: Платёжный провайдер

- Статус: proposed (статус известен, договор ещё не заключён)
- Дата: 2026-10-29, факты обновлены 2026-11-03

## Контекст
Нужны онлайн-оплата картами/СБП, чеки по 54-ФЗ, webhooks с подписью, идемпотентность. С 2026-11-03 известно: заказчица самозанятая, самозанятость оформлена в Сбере, чеки приходят туда. Договора с платёжным сервисом нет.

## Варианты
ЮKassa, T-Bank, Prodamus, CloudPayments — сравнение в ARCHITECTURE.md §4. Условия и комиссии [проверить].

## Решение
Рекомендация к заявке, не принятый договор: ЮKassa, потому что чеки уже живут в Сбере. Если самозанятую с цифровыми товарами не подключат — запасной адаптер Prodamus. Код пишется через интерфейс `PaymentProvider`, смена провайдера не переписывает заказы. Адаптер не начинать, пока нет команды и тестового магазина.

## Последствия
Подавать заявку провайдеру нужно сразу: модерация может блокировать этап 4.
