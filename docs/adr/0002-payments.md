# ADR-0002: Платёжный провайдер

- Статус: proposed (ожидает ответа на вопрос 1 в client-questions.md)
- Дата: 2026-10-29

## Контекст
Нужны онлайн-оплата картами/СБП, чеки по 54-ФЗ, webhooks с подписью, идемпотентность. Статус заказчицы (самозанятая или ИП) пока неизвестен.

## Варианты
ЮKassa, T-Bank, Prodamus, CloudPayments — сравнение в ARCHITECTURE.md §4. Условия и комиссии [проверить].

## Решение
Предварительно: самозанятая → Prodamus или ЮKassa; ИП → ЮKassa или T-Bank. Код пишется через интерфейс `PaymentProvider`, поэтому замена провайдера — новый адаптер без изменения заказов.

## Последствия
Подавать заявку провайдеру нужно сразу: модерация может блокировать этап 4.
