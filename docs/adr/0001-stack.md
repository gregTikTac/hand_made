# ADR-0001: Стек — Django + admin + HTMX/Alpine + Tailwind

- Статус: accepted (часть про Tailwind уточнена ADR-0005: используется кастомный CSS на токенах)
- Дата: 2026-10-29

## Контекст
Один разработчик на Python, ограниченный бюджет, нетехническая заказчица должна сама управлять товарами, акциями и предзаказами. Важны SEO и скорость на мобильных.

## Варианты
1. Django + встроенная админка + HTMX/Alpine + Tailwind.
2. Next.js + Headless CMS (Strapi/Payload).
3. FastAPI + React-админка.

## Решение
Вариант 1. Админка, ORM, миграции, формы, auth и sitemap есть из коробки; SSR без отдельного фронтенд-приложения; один язык и один деплой.
Tailwind — через standalone CLI (без Node в проде). Тема админки — django-unfold (проверить актуальность и лицензию перед этапом 1).

## Последствия
- Интерактив ограничен HTMX/Alpine — для магазина достаточно.
- Админку нужно доработать (inline-фото, подсказки, actions) — заложено в этапы 2 и 6.
