# ADR-0004: Выдача PDF

- Статус: accepted
- Дата: 2026-10-29, принято 2026-11-04

## Контекст
PDF — платный товар; покупатель без аккаунта; файлы могут быть тяжёлыми; нужно ограничить распространение.

## Варианты
1. Вложение в письмо.
2. Прямая presigned-ссылка S3 в письме.
3. Ссылка на сайт `/d/<token>/` → проверка лимитов → короткоживущий presigned URL.

## Решение
Вариант 3. Приватный бакет; токен (храним хеш) с TTL 30 дней и лимитом 5 скачиваний. На S3 ссылка короткая и подписанная, локально файл отдаёт сам сайт. Водяной знак «Куплено: email, заказ №» ставится при отправке.

## Последствия
Учёт скачиваний и отзыв ссылок; нужна форма «Не пришло письмо?» и повторная отправка из админки.
