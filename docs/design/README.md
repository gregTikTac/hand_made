## Шрифты (Google Fonts, есть кириллица)
- Заголовки: **Cormorant Garamond** 500/600/700 — элегантная антиква, «ручная» атмосфера.
- Текст: **Manrope** 400–700 — хорошо читается на маленьких экранах.
- Альтернативы при желании заказчицы: Playfair Display / Lora + Inter / Nunito Sans.
- В проекте: подключить локально (self-host, `font-display: swap`), чтобы не зависеть от Google и не передавать IP посетителей третьей стороне.

## Сетка 2 в ряд (ключевое требование)
- 390px: `(390 − 2×16 − 12) / 2 ≈ 173px` на карточку. Цена + старая цена помещаются в одну строку до «1 290 ₽ / 1 790 ₽»; при большей длине — перенос (flex-wrap), кнопка всегда во всю ширину карточки.
- Название — максимум 2 строки (line-clamp), поэтому высота карточек одинакова при длинных названиях.
- ≥1024px — 4 в ряд; на главной в «Популярных» — тоже.

## Решения UX
- Корзина и чекаут — **одна страница** (меньше шагов на телефоне); кнопка оплаты неактивна, пока нет валидного email и обязательного согласия.
- Повтор email — защита от опечаток (иначе файл уйдёт «в никуда»); альтернатива — подсказка «Возможно, вы имели в виду @yandex.ru?».
- На карточке товара на мобильном — липкая полоса «цена + В корзину» над нижней навигацией.
- Видео — слайд галереи; iframe грузится только по клику (скорость).
- Вся карточка в каталоге кликабельна, кнопка «В корзину» — отдельная зона над ссылкой.

## Скриншоты
Скриншоты 390px и 1280px создаются скриптом `/tmp/mock/shots.py` (Playwright, Chromium). В этой сессии Docker слой `bab4df8c200f` (Playwright-образ) не скачался из-за проблем со связью — процесс был остановлен. Для генерации нужен Docker или система с рабочим интернетом:

```bash
docker run --rm \
  -v $PWD/docs/design:/design:ro \
  -v $PWD/docs/design/screenshots:/out \
  -v /tmp/mock/shots.py:/shots.py:ro \
  mcr.microsoft.com/playwright/python:v1.48.0-jammy \
  bash -c 'pip install -q playwright==1.48.0 && python /shots.py'
```

До того как скриншоты будут готовы, показать заказчице HTML-страницы в DevTools 390×844.
