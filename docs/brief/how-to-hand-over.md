# Как передать фото и описания мастер-классов

Это инструкция для Екатерины. Так материалы попадут на сайт без ручной перекладки из переписки. Четыре карточки, которые уже пришли в Telegram (Лисичка, Забавные овечки, Козлёнок Боря, Плюшевые копытца), — образец. Остальные нужны в том же составе.

Пришлите **одной папкой** (архив или ссылка на Яндекс Диск / Google Drive). Не присылайте всё одним альбомом в Telegram: там пропадают имена файлов, и непонятно, где кончается один мастер-класс и начинается другой.

## Папка одного мастер-класса

Имя папки — короткое латинское, строчными буквами, слова через дефис. Это адрес страницы. Примеры: `lisichka`, `kozlyonok-borya`, `plyushevye-kopytca`.

```
lisichka/
  photos/
    01.jpg          ← обложка, её видят в каталоге
    02.jpg
    03.jpg
  materials.jpg     ← одно фото «что нужно для вязания», если оно есть
  lisichka.pdf      ← сам мастер-класс
  about.txt         ← текст карточки, образец ниже
```

Фото в `photos/` нумеруйте с нуля впереди: `01`, `02`, … `10`. Первое — готовая игрушка, дальше процесс, детали, одежда. Вертикальные кадры 4:5 подходят лучше всего. Форматы: JPG, PNG или WebP, каждый файл до 15 МБ.

Не кладите в папку:

- уменьшенные копии с суффиксом `_thumb`;
- скриншоты переписки и макеты сайта;
- несколько PDF в одной папке — нужен один файл мастер-класса.

Водяной знак «Зуева Екатерина / @baloo_hand» на фото можно оставить.

## Текст в about.txt

Скопируйте блок и заполните. Пустое поле так и оставьте пустым, не ставьте прочерк.

```
Название: Мастер-класс «Лисичка»
Цена, рубли: 450
Это комбо (да/нет): нет
Высота, см: 30
Длина, см:
Видео внутри мастер-класса, штук: 0
Как вяжется: цельно вязаная, пришиваем только ушки и мордочку
Одежда входит в мастер-класс (да/нет): да
Ссылки на видео:
Описание:
Вас ждёт подробный и понятный мастер-класс с большим количеством фотографий процесса вязания и сборки игрушки. Моя поддержка на любом этапе вязания! Лисичка цельно вязаная, пришиваем только ушки и мордочку. Высота 30 см. Описание воротничка входит в мастер-класс!
```

Пояснения:

- **Цена** — обычная цена без акции, целое число рублей. Скидку «−30%» на сайте включаем отдельно, в текст её писать не нужно.
- **Комбо** — «да», если в покупку входит несколько игрушек, как «Плюшевые копытца».
- **Длина** — только если она важна, как у овечек (14 см высота, 20 см длина). Иначе строку не заполняйте.
- **Видео** — число роликов внутри PDF. Ссылки на VK Видео, Rutube или YouTube пишите отдельными строками в «Ссылки на видео», если ролик должен открываться на сайте. Свои видеофайлы на сайт пока не загружаем.
- **Как вяжется** — одна фраза: что пришивается, что вяжется целиком.
- **Описание** — тот текст, который уже есть в постах. Общую фразу «PDF, схемы, доставка на почту» повторять не нужно: она и так есть на сайте.

## Таблица, если папок много

Рядом с папками можно положить один файл `products.csv` (Excel → «Сохранить как CSV»). Колонки:

`папка, название, цена, комбо, высота_см, длина_см, видео, как_вяжется, одежда, описание`

Одна строка — один мастер-класс. Имя в колонке «папка» совпадает с именем папки.

## Проверка перед отправкой

- У каждого мастер-класса есть PDF и хотя бы одна фотография готовой игрушки.
- Обложка — файл `01` в папке `photos`.
- Цена совпадает с той, что должна стоять на сайте.
- В описании нет чужих мастер-классов и нет текста «скидка только сегодня», если это не постоянное условие.

Когда папка будет готова, пришлите ссылку. Мы загрузим её командой импорта: фото станут галереей, PDF уйдёт в закрытое хранилище и не будет лежать в открытом доступе.
