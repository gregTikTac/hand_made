## Общая структура карточки

Каждый мастер-класс содержит:

1. **Цена** в начале (450₽ / 400₽ / 450₽ / 600₽).
2. **Заголовок** «Мастер-класс «Название»».
3. **Бойлерплейт**:
   > Мастер-класс по вязанию амигуруми крючком в формате PDF. Схемы, пошаговые фото и список материалов. Доставка на почту сразу после оплаты.
4. **Описание**:
   - повторный заголовок;
   - обещание подробного и понятного МК с большим количеством фото;
   - упоминание видео (если есть);
   - «Моя поддержка на любом этапе вязания!»;
   - конструктивные особенности (цельно вязаная / пришиваемые детали);
   - размеры;
   - дополнительно: входит описание одежды / воротничка.
5. **Набор фото**: первая — **заглавная**, остальные — процесс вязания, детали, материалы.
6. **Видео** внутри МК: 0, 1, 3 или 7 штук.

## Выводы для сайта
- В карточке товара должно быть несколько фото, включая «процесс».
- Было бы полезно добавить поля: **высота**, **количество видео**, **особенности конструкции**, **входит ли одежда**.
- Надпись на фото (watermark) — уже есть у автора: белый текст внизу фото. Но это авторский водяной знак, а не персонализированный для покупателя.
- Ценовой диапазон 400–600 ₽; комбо (3 в 1) стоит дороже — 600 ₽.
- Имя/ник автора для футера и страницы «Об авторе»: Екатерина Зуева, @baloo_hand.
- Заглавные фото — вертикальные (4:5), одна горизонтальная (фото 32, альбомная ориентация). Это подтверждает нужность `object-fit: cover` и `aspect-ratio: 4/5` для превью.
